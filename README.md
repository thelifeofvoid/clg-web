# CLG WEB

This folder contains both Sachin Kekan projects:

- `portfolio` — the personal portfolio website
- `fix-my-ride` — the Fix My Ride research prototype

## Start both websites

Double-click `start-both.cmd` in this folder.

- Portfolio: http://localhost:5174
- Fix My Ride: http://localhost:5173

The launcher starts only the host that is not already running and opens both pages in your browser.
